# Varin 手机交互设计稿

在仓库根目录安装项目依赖后运行以下命令，在浏览器打开 [本地预览](http://127.0.0.1:5192/)。

```sh
bun x vite --config docs/design/mobile-preview/vite.config.mjs
```

从「合作演示」里的文件可以进入全文、选中一段并引用到原对话。左上角返回会话列表，从这里可以进入群聊、处理「访谈笔记」里待回复的问题，或切到工作台看父子任务和文件改动。桌面预览顶部可以切换手机、平板和明暗主题。

列表左上是 Varin／工作台模式菜单。「助手」旁可以创建 Bot，顶栏文件夹按钮可以新建分组，Bot 行末可以调整归属。会话菜单可以创建单聊或群聊。Bot 对话右上打开正式版面板，包含概览、动态、记忆和日程。用量和 MCP 的快捷入口放在工作台对话顶栏。

主题、图标、头像资源、按钮、编辑器和消息菜单来自产品代码。会话及附件使用示例数据，发送和编辑草稿只作用于当前浏览器标签页。麦克风只展示布局。预览使用独立端口，无需启动 Varin 服务。
